偏角ソートのポイント

atan2 方式： 各点の角度を atan2(y, x) で求め、角度の小さい順に並べます。実装しやすい一方、浮動小数点の誤差に注意します。

外積方式： ベクトル a=(x₁,y₁)、b=(x₂,y₂) に対して cross = x₁y₂ − y₁x₂ を計算します。半平面で角度の範囲を分けたうえで、外積の符号から順序を判定できます。同じ方向の点は距離²で並べることができます。

注意： このツールでは、正の x 軸から反時計回りの順に並べます。原点の点は偏角が定義できないため入力対象外です。凸包などで使う場合は、基準点や同一直線上の点の扱いに応じて比較関数を調整してください。

比較関数の C++ 例（外積方式）

struct Point { long long x, y; };

int half(Point a) {
    // 上半平面（正のx軸を含む）を先にする
    return (a.y > 0 || (a.y == 0 && a.x >= 0)) ? 0 : 1;
}

bool cmp(Point a, Point b) {
    if (half(a) != half(b)) return half(a) < half(b);
    long long cr = a.x * b.y - a.y * b.x;
    if (cr != 0) return cr > 0; // a の方が反時計回りで先
    return a.x*a.x + a.y*a.y < b.x*b.x + b.y*b.y;
}
